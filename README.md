# ✈️ Штурманский бортовой журнал (ШБЖ) с расчетом НТС и топлива

Интерактивный штурманский план полета (ШБЖ) гражданской авиации с автоматическим расчетом навигационного треугольника скоростей (НТС) через острый угол $\\alpha$ и расчетного топлива.

### 🌐 GitHub Pages:
[https://alphagames35.github.io/shbj/](https://alphagames35.github.io/shbj/)

### Особенности:
- **Официальный авиационный дизайн (EFB)**: темная графитовая тема планшета, компактная шапка, шторка-меню и нижняя панель быстрого доступа на смартфонах.
- **Расчет НТС по методике летных училищ (Сасово / УВАУ ГА)**:
  - $\\delta_{\\text{н}} = \\delta_{\\text{мет}} \\pm 180^\\circ$
  - $\\text{УВ} = (\\delta_{\\text{н}} - \\text{МПУ} + 360^\\circ) \\pmod{360^\\circ}$
  - Острый угол $\\alpha \\in [0^\\circ, 90^\\circ]$ по 4 четвертям
  - {\\text{бок}} = U \\sin \\alpha, \\quad U_{\\text{экв}} = U \\cos \\alpha$
  - $\\text{УС} = \\arcsin(U_{\\text{бок}} / V_{\\text{и}})$
  - $\\text{МК} = (\\text{МПУ} - \\text{УС} + 360^\\circ) \\pmod{360^\\circ}$ (колонка защищена от изменения)
  -  = V_{\\text{и}} \\cos(\\text{УС}) \\pm U_{\\text{экв}}$
  -  = (S / W) \\cdot 60$, расчетное время пролета (ЕТА / Т расч)
- **Топливный расчет**:
  - Ввод расхода в час (кг/ч) и в минуту (кг/мин) с двухсторонней автосинхронизацией.
  - Учет аэронавигационного запаса (АНЗ).
  - Автоматический расчет общей необходимой заправки: {\\text{запр}} = \\sum Q_{\\text{р}} + \\text{АНЗ}$.
- **Печать**:
  - Адаптированный стиль @media print для идеального вывода на 1 лист формата А4 (альбомная ориентация).
  - Скрытие панели управления и сохранение официального вида бумажного бланка.
- **Автосохранение**: в локальное хранилище браузера (localStorage).
