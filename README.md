## 📖 О проекте

**Штурманский бортовой журнал (ШБЖ)** — интерактивное веб-приложение класса **EFB (Electronic Flight Bag)** для штурманской подготовки и навигационного расчета полета в гражданской авиации.

Бланк строго следует классической отраслевой **Форме 3047** летных училищ гражданской авиации (**СЛУ ГА Сасово**, **УВАУ ГА / УИ ГА**, **СПбГУ ГА**, **АУЦ**) и требованиям **ФАП-128 / ФАП-136**.

Приложение объединяет интерактивное редактирование «на лету», автоматизированный навигационный треугольник скоростей (НТС), расчет топлива с АНЗ, температурную поправку безопасных высот и идеальный экспорт на бумагу строго на **1 лист формата А4 (альбомная ориентация)**.

## 🌟 Ключевые возможности

### 🧭 1. Навигационный расчет (НТС через острый угол $\alpha$)
* **Автоматический навигационный ветер**: пересчет метеорологического направления $\delta_{\text{мет}} \leftrightarrow \delta_{\text{н}}$ ($\pm 180^\circ$).
* **Строгий расчет по 4 четвертям**: определение навигационного угла ветра $\text{УВ}$ и острого угла $\alpha \in [0^\circ, 90^\circ]$ между МПУ и направлением ветра.
* **Защита расчетных колонок**: ячейки $\text{УВ} / \alpha$, $\text{УС}$, $\text{МК}$ и $W$ вычисляются автоматически и защищены от случайной перезаписи.
* **Переключение режима отображения**: возможность переключать показ угла в заголовке таблицы: **$\alpha$ (0°–90°)** или **УВ (0°–360°)** в один клик.

### ⛽ 2. Комплексный топливный расчет & АНЗ
* **Двухсторонняя автосинхронизация расхода**: ввод расхода топлива в час ($\text{кг/ч}$) или в минуту ($\text{кг/мин}$) с автоматическим пересчетом.
* **Расчет этапов $Q_{\text{р}}$**: расчет расхода на каждый участок маршрута по путевой скорости $W$ и времени $t$.
* **Учет аэронавигационного запаса (АНЗ)**: суммирование топлива маршрута и резерва в итоговую необходимую заправку:
  $$Q_{\text{запр}} = \sum Q_{\text{р}} + \text{АНЗ}$$

### 🛡️ 3. Расчет безопасной высоты $H_{\text{б.пр}}$ (ФАП-136)
* Пилот вводит только абсолютную высоту препятствий с учетом рельефа $H_{\text{преп}}$.
* Приложение автоматически рассчитывает безопасную приведенную высоту $H_{\text{б.пр}}$ с учетом истинной безопасной высоты ($100\,\text{м}$ или $200\,\text{м}$) и фактической температуры у земли $t_0$ через методическую температурную поправку высотомера $\Delta H_t$.

### ⏱️ 4. Времена этапов и умный прогноз $Т_{\text{факт}}$
* **Официальный авиационный формат**: время этапов отображается в виде `ч.мм` (например: $4\,\text{мин} \to \mathbf{0.04}$, $19\,\text{мин} \to \mathbf{0.19}$, $1\,\text{ч}\,15\,\text{мин} \to \mathbf{1.15}$).
* **Автоматические времена на взлет и посадку**: гибкая настройка времени набора и захода (по умолчанию $t_{\text{взл}} = 4\,\text{мин}$, $t_{\text{пос}} = 6\,\text{мин}$).
* **Каскадный расчет $Т_{\text{расч}}$**: расчетное время пролета всех поворотных пунктов маршрута.
* **Ghost-прогноз для $Т_{\text{факт}}$**: при вводе фактического времени на любом ППМ следующие пункты автоматически получают прогнозное время, отображаемое полупрозрачным шрифтом. Двойной клик мгновенно фиксирует прогноз в факт.

### 🔄 5. Мультисистемный переключатель единиц (Units Switcher)
Интерактивное переключение единиц измерения с автоматическим пересчетом всех заполненных данных:
* 🚀 **Скорость**: $\text{км/ч} \longleftrightarrow \text{узлы (kt)}$
* ⛰️ **Высота**: $\text{метры (м)} \longleftrightarrow \text{футы (ft / FL)}$
* 📏 **Расстояние**: $\text{километры (км)} \longleftrightarrow \text{морские мили (NM)}$

### ⚡ 6. Генеральное заполнение скорости $V_{\text{и}}$
* Кнопка **«⚡Все»** в шапке таблицы и панели параметров.
* Всплывающая подсказка при вводе $V_{\text{и}}$ для мгновенного распространения выбранной скорости на все этапы полета с данными.

### 🖨️ 7. Вывод на печать строго на 1 лист А4 (Landscape)
* Калиброванные стили `@media print`:
  * **Слева**: Заголовок «ШТУРМАНСКИЙ БОРТОВОЙ ЖУРНАЛ №», данные экипажа, дата, воздушное судно.
  * **По центру**: Таблица ветра по высотам и эшелонам ($\delta$, $U$).
  * **Справа**: Таблица восхода/захода солнца.
  * **Основная часть**: 13 строк маршрута, аэродромные данные, погода, блок заметок с разлиновкой, схема круга аэродрома (коробочка) и роза ветров.
  * **Подвал**: расчет рубежей ухода, запасных аэродромов и подписи экипажа (*КВС, 2-й пилот, Штурман АЭ, Дежурный штурман*).
* **Никаких полос прокрутки** и лишних элементов интерфейса при печати или экспорте в PDF.

### 📷 8. Сохранение фотографии бланка (PNG / JPEG)
* **Мгновенный экспорт в высоком разрешении (2x Retina)** в один клик кнопкой **«📷 Фото»** в шапке или боковом меню.
* Выгрузка чистого официального бланка без элементов управления в галерею смартфона или папку «Загрузки».
* Поддержка форматов **PNG** (без потери качества) и **JPEG** (компактный размер).
* Автоматическое присвоение имени файла по номеру рейса и дате: `SHBJ_N{№}_{Дата}.png`.

## 📐 Методика расчета НТС (Школа Сасово / УВАУ ГА)

```
                            Север (С)
                               ▲
                               │    δн (куда дует)
                               │   ↗
                               │  /
                               │ /
                               │/ ) УВ
  Запад (З) ───────────────────┼───────────────────► Восток (В)
                              /│\
                             / │ \
                            /  │  \ МПУ (линия пути)
                           /   │   ▼
                               │
                               ▼
                            Юг (Ю)
```

Математический аппарат навигационного треугольника скоростей:

### 1. Навигационный ветер
Направление, **куда** смещаются воздушные массы:
$$\delta_{\text{н}} = (\delta_{\text{мет}} \pm 180^\circ) \pmod{360^\circ}$$

### 2. Угол ветра (УВ)
Угол между линией пути (МПУ) и направлением навигационного ветра:
$$\text{УВ} = (\delta_{\text{н}} - \text{МПУ} + 360^\circ) \pmod{360^\circ}$$

### 3. Острый угол ветра $\alpha \in [0^\circ, 90^\circ]$ по 4 четвертям
В летных училищах расчет ведется через острый угол $\alpha$ к ближайшему направлению ветра:

| Четверть | Диапазон УВ | Формула $\alpha$ | Характер ветра | Знак УС | Знак $U_{\text{экв}}$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **I** | $0^\circ \le \text{УВ} \le 90^\circ$ | $\alpha = \text{УВ}$ | Попутно-правый | $+$ (вправо) | $+$ (попутный) |
| **II** | $90^\circ < \text{УВ} \le 180^\circ$ | $\alpha = 180^\circ - \text{УВ}$ | Встречно-правый | $+$ (вправо) | $-$ (встречный) |
| **III** | $180^\circ < \text{УВ} \le 270^\circ$ | $\alpha = \text{УВ} - 180^\circ$ | Встречно-левый | $-$ (влево) | $-$ (встречный) |
| **IV** | $270^\circ < \text{УВ} < 360^\circ$ | $\alpha = 360^\circ - \text{УВ}$ | Попутно-левый | $-$ (влево) | $+$ (попутный) |

### 4. Составляющие ветра (боковая и эквивалентная)
$$U_{\text{бок}} = U \cdot \sin \alpha, \qquad U_{\text{экв}} = U \cdot \cos \alpha$$

### 5. Угол сноса (УС) и Магнитный курс (МК)
$$\sin(\text{УС}) = \frac{U_{\text{бок}}}{V_{\text{и}}} \implies |\text{УС}| = \arcsin\left(\frac{U_{\text{бок}}}{V_{\text{и}}}\right)$$

$$\text{МК} = (\text{МПУ} - \text{УС} + 360^\circ) \pmod{360^\circ}$$

### 6. Путевая скорость ($W$)
$$W = V_{\text{и}} \cdot \cos(\text{УС}) \pm U_{\text{экв}}$$
*(знак $+$ при попутной составляющей ветра, $-$ при встречной)*

### 7. Время полета этапа ($t$)
$$t_{\text{мин}} = \left(\frac{S}{W}\right) \cdot 60 \implies \mathbf{\text{ч.мм}}$$

## ⌨️ Горячие клавиши и управление

| :--- | :--- |

## 🚀 Локальный запуск

Для работы с журналом не требуется интернет, Node.js или веб-сервер. 

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/AlphaGames35/shbj.git
   ```
2. Откройте файл `index.html` двойным кликом в любом браузере (Chrome, Edge, Safari, Firefox, Яндекс.Браузер).
